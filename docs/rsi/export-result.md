# 模型导出结果与部署

导出结束后，「模型导出 → 运行时」会保留**最近一次导出**状态卡（不再只在运行中显示任务）：

- 成功 / 失败徽章、exit code、结束时间
- 清晰的 `output_dir`（合并或量化产物路径）
- 失败时附带日志末尾错误片段
- 本轮最近若干次导出记录（路径 + 时间 + 状态）

成功后可点**用该模型部署推理**：跳到「推理服务」，把 `--model` 预填为该 `output_dir`，并清空 `--adapters`（已是完整权重，无需 LoRA）。再点页面上的部署按钮即可。

修改静态资源或 `rsi` 后端后需重启 RSI（`./run.sh restart`）才能看到新 UI。
